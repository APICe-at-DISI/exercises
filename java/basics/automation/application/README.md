# Compilazione ed esecuzione di un progetto con Gradle

1. Scaricare il wrapper di gradle: https://github.com/DanySK/Gradle-Wrapper/archive/refs/heads/master.zip
2. Configurare correttamente il file `build.gradle.kts` per far si che compili il progetto
3. Assicurarsi che il progetto compili e sia eseguibile
4. Lanciare l'applicazione prima tramite java
5. Modificate il file `build.gradle.kts` per specificare la classe principale del progetto (i.e., quella contente il metodo main)
6. Lanciare l'applicazione tramite Gradle
