# Unit testing con JUnit 6

Si consideri il dominio *Banking* dei laboratori precedenti: `AccountHolder`, `BankAccount` e le loro implementazioni.

1. Osservare la classe `TestSimpleBankAccount`, che testa l'implementazione `SimpleBankAccount`.
2. Scrivere i test descritti nella classe `TestStrictBankAccount`, che testa `StrictBankAccount`.

Note: consultare la [JavaDoc di JUnit 6](https://docs.junit.org/6.0.0/api/org.junit.jupiter.api/org/junit/jupiter/api/package-summary.html)
